# Advanced SQL Queries Assignment

This repository contains solutions for advanced SQL query tasks performed using MySQL.

The assignment focuses on writing structured and efficient SQL queries using advanced database concepts for data analysis and management.

## Topics Covered

- LEFT JOIN
- Subqueries
- Nested JOINs
- Common Table Expressions (CTE)
- RANK() and DENSE_RANK()
- CASE Statements
- Salary-Based Analysis Queries

## Database Used

- MySQL 8.0

## Files Included

- `Assignment3_NargisKhatoon.sql`
- Query output screenshots
- README documentation

## Objective

The objective of this assignment is to strengthen advanced SQL querying skills and improve understanding of relational database operations.
