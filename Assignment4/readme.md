# SQL Data Modification & Integrity Operations

This repository contains solutions for Assignment 4 based on data modification, integrity constraints, and database optimization using MySQL.

The assignment focuses on performing essential database operations such as updating records, deleting unwanted data, creating reusable views, applying constraints, indexing tables, and working with stored procedures.

## Concepts Covered

- Updating Records with `UPDATE`
- Deleting Data using `DELETE`
- Creating SQL Views
- Applying `CHECK` Constraints
- Creating Indexes for Faster Search
- Stored Procedures in MySQL
- Data Integrity & Optimization

## Technologies Used

- MySQL 8.0
- SQL

## Repository Contents

- `Assignment4_NargisKhatoon.sql` — Complete SQL queries for all tasks
- `screenshots/` — Query execution and output screenshots
- `README.md` — Assignment documentation

## Objective

The main objective of this assignment is to understand how SQL is used to manage, protect, and optimize database records through practical database operations.
