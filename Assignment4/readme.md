# Assignment 4: Data Modification & Integrity

## Objective
This assignment focuses on performing data modification operations and maintaining data integrity in SQL using different database concepts.

## Tasks Performed

1. Updated employee salaries in the **Sales** department by **10%** using the `UPDATE` statement.

2. Deleted employees working in the **Obsolete** department using the `DELETE` statement.

3. Created a **View** to display employees with salary greater than **80000**.

4. Added a **CHECK Constraint** to ensure employee salary is always greater than **0**.

5. Created an **Index** on employee last names to improve search performance.

6. Created a **Stored Procedure** to retrieve employees based on a department name.

This assignment helped in understanding how to modify data, enforce integrity rules, optimize searching, and use advanced SQL features for database management.
