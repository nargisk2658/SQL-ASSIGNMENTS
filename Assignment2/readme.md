# SQL Assignment 2 – Employee Database Queries

## Overview

This project demonstrates the use of SQL queries on an Employee Database using MySQL. The assignment focuses on retrieving, filtering, sorting, and analyzing employee data through different SQL operations.

## Technologies Used

* SQL
* MySQL 8.0
* MySQL Command Line Client

## Database Information

**Database Name:** `company_db`

### Tables Used

* employees
* departments
* companies

## SQL Operations Performed

* Displayed all tables from the database
* Described the structure of the employees table
* Retrieved complete employee records
* Filtered employees belonging to the Sales department
* Displayed distinct job titles
* Sorted employee data by salary in descending order
* Counted the total number of employees
* Calculated average salary department-wise
* Retrieved employee names along with their job titles

## Key Concepts Covered

* Data Retrieval using `SELECT`
* Data Filtering using `WHERE`
* Sorting using `ORDER BY`
* Removing duplicate values using `DISTINCT`
* Aggregate Functions (`COUNT`, `AVG`)
* Grouping data using `GROUP BY`
* Table structure analysis using `DESCRIBE`

## Output

All queries were executed successfully in MySQL with verified outputs.

## Repository Purpose

This repository is created to practice and strengthen SQL query writing, database handling, and data analysis concepts using MySQL.
