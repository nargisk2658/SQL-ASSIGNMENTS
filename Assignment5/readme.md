# Transactions, Logic & Analysis in SQL

This repository contains solutions for Assignment 5 based on advanced SQL transaction handling, recursive queries, analytical functions, and database backup operations using MySQL.

- SQL Transactions
- COMMIT Operations
- EXISTS Clause

- GROUP BY with ROLLUP
- Database Export using mysqldump
